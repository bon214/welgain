# welgain — Frame playground

添付された画面を基にした、フレームのサイズ変更だけを試すWebアプリです。Figma の全画面再現ではなく、レイアウト操作のプロトタイプです。

- 中央の**縦バー**をドラッグすると、3Dモデル枠と右側の幅が変わります。
- 右側の**横バー**をドラッグすると、グラフ枠とアイコン群枠の高さが変わります。
- 「標準」「グラフ重視」「モデル重視」で比率を切り替えられます。
- スナップを有効にすると、プリセットに近い比率に吸着します。
- マウス・タッチ・キーボードに対応しています。
- レイアウトはブラウザの `localStorage` に保存されます。外部へのデータ送信はありません。

3Dモデル、グラフ、アイコンは枠を確認するためのプレースホルダーです。人体描画、計測、録画、センサー接続は実装していません。

## GitHub からブラウザで試す

GitHub リポジトリにコードを置くだけでは、Webアプリとしては実行されません。サイトを公開せずにブラウザで触る場合は **GitHub Codespaces** を使えます。

1. このリポジトリの **Code → Codespaces → Create codespace on main** を選びます。
2. 初回の依存関係インストールが終わると開発サーバーが自動起動します。
3. 自動で画面が開かない場合は、**Ports** タブの **5173** で **Open in Browser** を選びます。
4. ポートの表示範囲は **Private** のまま利用してください。GitHub Pages などへのデプロイは不要です。

Codespaces の利用権限・利用枠が必要です。実際の Codespaces 作成は、このリポジトリの動作検証には含まれていません。

## 手元のPCで試す

Node.js 24 と npm を用意し、以下を実行します。

```sh
git clone https://github.com/bon214/welgain.git
cd welgain
npm ci
npm run dev
```

ターミナルに表示される開発サーバーのアドレスをブラウザで開きます。停止するときは `Ctrl+C` を押します。

## 操作

| 操作                       | 動作                                       |
| -------------------------- | ------------------------------------------ |
| 縦・横の分割バーをドラッグ | 左右・上下のサイズを変更                   |
| 分割バーをダブルクリック   | その方向だけ標準サイズに戻す               |
| 分割バーを選択して矢印キー | 2%ずつ調整                                 |
| Shift＋矢印キー            | 10%ずつ調整                                |
| Home / End                 | 最小 / 最大サイズ                          |
| Shift を押しながらドラッグ | スナップを一時的に解除                     |
| リセット                   | 標準レイアウトに戻し、スナップを有効にする |

分割バーには最小・最大サイズがあり、枠が潰れないようにしています。「モデルの幅」は左右の合計に対する比率、「グラフの高さ」は右側の上下の合計に対する比率です。分割バー自体の幅は含めません。

## 開発・検証

React + TypeScript + Vite。バックエンド、データベース、APIキーは不要です。

```sh
npm run build
npm test
npm run format:check
```

ブラウザテストは Playwright を使います。`/usr/bin/chromium` があれば利用し、なければ先に以下を実行してください。

```sh
npx playwright install chromium
# Linux でシステムライブラリも必要な場合:
npx playwright install --with-deps chromium
```

別の Chromium 実行ファイルを使う場合は、環境変数 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` を設定できます。テストはポート 5173 に開発サーバーを起動します。

テスト対象は、縦横のドラッグ、寸法の変化、スナップ、保存・復元、プリセット、キーボード操作、サイズ制限、スマートフォンのタッチ操作、保存不可の場合の動作です。

クラウド環境では `bash .devcontainer/start.sh` で起動・再接続できます。起動済みの場合は二重起動しません。ログは `/tmp/welgain-vite.log` に保存します。
